## 🌟 Overview

**SnapBio** is a modern, privacy-focused Link-in-Bio platform designed for creators, indie hackers, writers, and digital agencies. Instead of cookie-cutter button links on bloated legacy platforms, SnapBio brings Notion-style minimalist typography, rich embed blocks, dynamic QR code generation, and instant page loading.

---

## ✨ Key Features

- **📝 Notion-Style Aesthetic**: Clean, elegant typography and intuitive block layouts that let your content shine.
- **⚡ Sub-Second Edge Delivery**: Rendered with Next.js App Router and optimized for instantaneous mobile social media browser loading (Instagram, TikTok, X, YouTube).
- **📱 Instant Dynamic QR Codes**: Generate downloadable vector and high-res QR codes directly inside the studio for print, business cards, and merchandise.
- **🔒 Privacy & Autonomy**: Zero tracking bloatware or intrusive third-party ads. Powered by Supabase row-level security.
- **🌐 Custom Domain & Slug Flexibility**: Claim your unique handle or map custom domains.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/mywgit/SnapBio.git
cd SnapBio

# Install dependencies
npm install

# Configure environment variables
cp .env.example .env.local

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view your local SnapBio studio.
